# VahterBot

## Исходный промпт

Спроектируй, используя typescript и `grammy` (используй MCP Context 7 для получения актуальной документации).

Необходимо создать антиспам телеграм-бота, который будет реагировать только на первое сообщение каждого пользователя в чате / комментариях к каналу.

Если пользователь в черном списке — сразу баним и удаляем его сообщения.

Если пользователь только присоединился (определяем это по соответствующему сообщению), то заносим его в базу в таблицу новых пользователей.

Далее проверяем его сообщение с помощью эвристик. Если по эвристикам это не спам — удаляем из таблицы новых и логируем сообщение. Если эвристики говорят, что это спам — заносим пользователя в таблицу спамеров, баним и удаляем его сообщения.

Особое внимание удели эффективности и безопасности.

Перед началом работы задай все необходимые вопросы.

## Ответы на уточняющие вопросы от модели
1. БД — sqlite, планирую держать в бакете Yandex Object Storage и маунтить в контейнер, где выполняется облачная функция
2. для деплоя используем serverless-функцию в Яндекс Облаке
3. Эвристики — это регексп, который я предоставлю отдельно
4. Управление у админов и отдельного списка администраторов
5. Логируем в файл
6. Работать должно одновременно во множестве чатов
7. Рантайм node.js
